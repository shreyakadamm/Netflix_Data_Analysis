# 🎬 Netflix Data Analysis

## 📌 Project Overview

This project is an interactive Netflix Data Analysis dashboard
developed using Python and Streamlit.

The project analyzes Netflix movies and TV shows to identify
patterns and trends based on content type, genres, ratings,
release years, countries, and other attributes.

The Streamlit application provides an interactive interface
for exploring the Netflix dataset through data analysis and
visualizations.

## 🎯 Objectives

- Analyze Movies and TV Shows available on Netflix
- Explore the most common genres
- Analyze Netflix content by release year
- Study country-wise content distribution
- Analyze content ratings
- Identify trends in Netflix's content library
- Present insights through an interactive dashboard

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit
- Jupyter Notebook

## 📂 Dataset

The project uses the Netflix Titles dataset containing information
about movies and TV shows available on Netflix.

Important columns include:

- Show ID
- Type
- Title
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Listed In
- Description

## 🔍 Data Analysis

The project includes:

- Data cleaning
- Handling missing values
- Exploratory Data Analysis (EDA)
- Movie vs TV Show analysis
- Genre analysis
- Country-wise analysis
- Rating analysis
- Release year analysis
- Data visualization

## 📊 Streamlit Dashboard

An interactive Streamlit dashboard was developed to allow users
to explore Netflix content dynamically.

Users can analyze different aspects of the dataset using
interactive filters and visualizations.

## 📈 Key Insights

The analysis provides insights into:

- Distribution of Movies and TV Shows
- Popular Netflix genres
- Content production by country
- Distribution of content ratings
- Netflix content trends over the years
- Comparison between Movies and TV Shows
